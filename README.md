# Devmini Dulari - Personal Portfolio Website

Personal portfolio website of **U.D.G. Devmini Dulari**, Software Engineer with a dual academic background in **Software Engineering** (Birmingham City University) and **Physical Science with Statistics & Computer Science** (University of Kelaniya).

Live portfolio showcasing completed software development projects, academic background, technical skills, and contact channels.

---

## 🌟 Key Features

- **Responsive Modern UI:** Designed with a dark/light theme switch, fluid typography, glassmorphic accents, and mobile drawer navigation.
- **Project Showcase & Dynamic Filtering:** Filter 15+ software projects across categories (Client Projects, Web Applications, Desktop Systems, Mobile & IoT, and Predictive/Stats) with real-time text search.
- **Interactive Project Modal:** Detailed modal inspects each project's architecture, key features, technology stack, and engineering takeaways.
- **Skills Matrix:** Categorized tabs for Programming & Web, Computer Science (DSA), AI Fundamentals, Statistics & Data, and Tools & Security.
- **Curriculum Vitae Preview:** Integrated modal for previewing a clean resume sheet with a one-click print / save to PDF option.
- **Interactive Ambient Background:** Lightweight HTML5 Canvas particle network animation with subtle glow accents.
- **Direct Contact & Mailto Integration:** Contact card grid with one-click email copying, toast feedback, and email form triggering.

---

## 🛠️ Built With

- **HTML5:** Semantic, accessible layout structure.
- **CSS3:** Custom properties (design tokens), Flexbox, CSS Grid, glassmorphism, responsive media queries, and print stylesheet.
- **Vanilla JavaScript (ES6+):** Pure JavaScript with zero external frameworks or heavy dependencies.
- **Fonts & Icons:** [Google Fonts](https://fonts.google.com/) (*Outfit*, *Plus Jakarta Sans*, *JetBrains Mono*) and [Font Awesome 6](https://fontawesome.com/).

## 🚀 Getting Started Locally

To run this portfolio locally on your machine:

### Option 1: Direct File Access
Simply double-click `index.html` or open it with your preferred web browser.

### Option 2: Local Web Server (XAMPP / VS Code Live Server / Python)
If serving via a local server (recommended for smooth asset loading):

```bash
# Using Python 3 built-in HTTP server:
python -m http.server 8000

# Open in browser:
# http://localhost:8000
```

Or place the folder in your XAMPP web root (`htdocs/portfolio`) and navigate to `http://localhost/portfolio`.
